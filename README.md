# Frontend - Choral Riff

## Description

Le frontend de Choral Riff fournit une interface web permettant aux utilisateurs de gérer leurs ensembles musicaux, morceaux et ressources associées.

Il communique avec l'API REST Spring Boot du backend pour accéder aux fonctionnalités métier de l'application.

## Technologies

* React 18
* JavaScript / TypeScript
* Vite
* Axios
* React Router
* CSS

## Fonctionnalités

* Authentification des utilisateurs
* Gestion des ensembles musicaux
* Gestion des morceaux
* Gestion des documents et ressources multimédias
* Gestion des notifications
* Navigation entre les différentes fonctionnalités de l'application
* Communication avec l'API REST Spring Boot
