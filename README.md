# Frontend - Choral Riff

## Description
Ce projet frontend permet d'interagir avec le backend Choral Riff pour gérer les ensembles musicaux.  
Il fournit une interface utilisateur pour créer, visualiser, modifier et supprimer des ensembles.

## Technologies
- React 18
- Axios (pour les appels API)
- React Router (navigation)
- CSS
